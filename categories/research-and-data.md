# Research & Data

| Umbrella repo | Covers | Status |
|---|---|---|
| [`open-ai-research-agent`](https://github.com/SamurAIGPT/open-ai-research-agent) | Web research, document ingestion, market/audience research | Coming Soon |
| [`open-ai-stock-research-agent`](https://github.com/SamurAIGPT/open-ai-stock-research-agent) | Public-company stock research — profile, financials, SEC filings, quote, price history, valuation/ratio screening. Read-only; not a trading/portfolio/investment-advice agent | Coming Soon |
| [`open-ai-analytics-agent`](https://github.com/SamurAIGPT/open-ai-analytics-agent) | Turning enriched/scraped data into client-facing reports and dashboards | Coming Soon |
| [`open-ai-competitor-intelligence-agent`](https://github.com/SamurAIGPT/open-ai-competitor-intelligence-agent) | Cross-cutting competitive audits (SEO + ads + social + reviews + pricing) | Blueprint |

`open-ai-research-agent` and `open-ai-analytics-agent` are Coming Soon — pending broader API coverage on Muapi across the categories these agents pull from. A related gap closed across 2026-09-24: Muapi now has code-complete (not yet deployed) public-company financial data (`company.public_financials` — profile, statements, SEC filings, quote), daily stock price history (`market.stock_history`), fundamental metrics/ratio screening (`market.stock_screener`), and crypto market data (`crypto.market_data` — quote, profile, history, markets, search), all read-only research data with no trading/portfolio/advice output. Rather than folding a public-company-brief sub-agent into `open-ai-research-agent`, the first three capabilities got their own new umbrella, `open-ai-stock-research-agent` — a narrower, SEO-honest name ("stock research," not "finance") chosen deliberately to avoid implying trading/investment-advice capability this repo doesn't have, matching the scope line the plan doc has held since it first rejected an `ai-finance-agent` umbrella. Crypto market data has no umbrella yet — same "no finance/trading agent" scope decision applies there too. `open-ai-competitor-intelligence-agent` moved Coming Soon → Blueprint (2026-09-09): its `ad-library-mining` sub-agent was already Blueprint, and `competitive-audit` is now Blueprint too — its SEO signal (`seo-domain-overview`/`seo-backlinks-history`) and social signal (`social.read_posts`) are live and tested, its reputation signal (`seo-business-reviews`) is live but Google-only. It runs a real, partial audit today rather than waiting on 100% channel coverage. Added a fifth signal (2026-09-10): the new `price-trial-monitoring` sub-agent extracts a competitor's pricing/plan/free-trial data directly from their own site via `company.products` — also Blueprint, same aggregator vendor-key blocker as the rest of this repo.
